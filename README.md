# API Automation Testing

## Overview

This project demonstrates API testing and automation using JavaScript and Playwright.

The goal is to validate REST API functionality, response data, status codes, and different API scenarios through automated tests.

## What I Test

- GET requests
- POST requests
- PUT requests
- DELETE requests
- HTTP status codes
- Response body validation
- Request and response data
- Positive and negative scenarios
- API data validation

## Tools & Technologies

- JavaScript

- Git & GitHub

## How to Run

Install dependencies:

```bash
npm install
```

Run the API tests:

```bash
npx playwright test
```

View the HTML test report:

```bash
npx playwright show-report
```
